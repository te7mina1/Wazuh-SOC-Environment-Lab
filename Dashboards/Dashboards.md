## Authentication Activity Dashboard

The Authentication Dashboard provides real-time visibility into successful and failed login attempts across monitored systems. It highlights authentication trends, targeted user accounts, host activity, and recent authentication events, enabling rapid identification of brute-force attacks and unauthorized access attempts.

---

## Endpoint Process Activity Dashboard

The Process Activity Dashboard visualizes endpoint process execution collected primarily from Microsoft Sysmon. It displays frequently executed processes, execution timelines, parent-child process relationships, user activity, and recent process events, supporting endpoint threat hunting and malware investigations.

---

## Network Traffic Overview Dashboard

The Network Dashboard presents firewall telemetry collected from pfSense, including network traffic volume, top communicating hosts, firewall pass/block decisions, protocol distribution, and recent network connections. This dashboard provides a centralized view of network activity for monitoring and investigation.
